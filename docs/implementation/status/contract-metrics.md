# Contract Metrics

## Purpose

Measure whether companion-skill guidance improves delivery before promoting it into stricter enforcement.

## Review Window

- Start date: 2026-07-11
- Review after: 2 to 4 weeks of real task usage

## Metrics

| Metric | Baseline | Current | Notes |
|---|---:|---:|---|
| Average sessions per implementation task | - | - | Lower is better when quality holds |
| Recap-heavy sessions requiring handoff | - | - | Lower is better |
| Validator failures per task | - | - | Lower is better |
| Tasks reopened due to unclear scope or acceptance criteria | - | - | Lower is better |
| Bug fixes with a reproducible failing loop before code changes | - | - | Higher is better |
| Time from approved design to ready task | - | - | Lower is better |

## How To Use

1. Capture a baseline from recent completed tasks.
2. Log updates weekly or per milestone.
3. Promote a companion-skill rule into validator enforcement only if the metric trend is favorable and the operational friction is acceptable.
